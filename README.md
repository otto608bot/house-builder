# Family House Builder

A fun drag-and-drop house building game for the kids!

Pick your character (Daddy, Gus, Toby, Mommy, or Eliza) and drag furniture, decorations, and more onto the house grid to create your dream home.

Built with the same playful, pastel, kid-friendly style as Eliza's Spelling Adventure.

## How to play
1. Choose a character.
2. Drag items from the toolbox onto the house.
3. Drag placed items to rearrange them.
4. Clear and start over anytime!

Open `index.html` in a browser or deploy to Netlify for a live link.
